# Custom Wake-Word Models Directory

Place custom trained openWakeWord ONNX models here.

### Supported Model Names:
- `jarvis.onnx`
- `hey_jarvis.onnx`
- `hey_jarvis_v0.1.onnx`

If no custom file is present, JARVIS will automatically use the official openWakeWord built-in `hey_jarvis_v0.1.onnx` model.
